Questions, answered

Before you open a file.

Capabilities, limits and the current public beta status.

Does Dev Inspector upload my files?

No. The app processes inspected files locally and does not upload inspected file contents. Inspection does not require a network connection.

Does it modify files?

No. Inspection is read-only. Generated text remains in the app and is not written back to the inspected source. Copy actions write selected data to the macOS clipboard.

Does it validate certificate trust?

No. Certificate date validity status describes the validity dates only. It does not validate the trust chain, hostname or revocation (OCSP/CRL). Within Validity Period does not mean trusted.

Does it verify IPA signatures?

No. IPA inspection reads archive and signing metadata. It does not verify a signature, prove that an app can be installed, install the app or re-sign it.

What macOS versions are supported?

The current planned release, Dev Inspector 1.0.0, requires macOS 14.0 or later.

Is Intel Mac supported?

The Universal 2 build includes Apple Silicon and Intel architectures. Intel real-machine validation is still pending before public release; current Intel coverage is a cross-build check.

Is automatic updating supported?

Automatic updates are not currently included. When a newer release becomes available, it will need to be installed manually.

Can I inspect large IPA files?

IPA archive input is capped at 2 GiB, with additional entry, directory and resource limits. The app reads archive metadata without extracting the entire archive. Some large or unusual archives may be rejected, and performance depends on their contents and your Mac. This is not unlimited archive support.

Why is download not available yet?

Public download is not available yet. Developer ID signing and notarization are pending. Current local artifacts are not offered as public downloads.

Is Dev Inspector free or paid?

Pricing has not been finalized. Pricing and purchase availability will be announced.

Can I open any ASN.1 document or use a Hex editor?

ASN.1 and Hex currently support certificate structure inspection. There is no general entry point for arbitrary ASN.1 files or standalone Hex editing.

What structured-data features are not included?

Raw → Tree navigation, XML Pretty, schema validation and an XPath engine are not implemented. JSON Pretty and Tree → Raw navigation are available.

Does profile parsing prove Apple trust?

No. Profile parsing shows team, App ID, devices, entitlements and embedded certificates, but does not assert Apple trust validation.

How do I contact support?

For product support, email dragon_kang_app@163.com. The Support page explains what to include in a sanitized report.
