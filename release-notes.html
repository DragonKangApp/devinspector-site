Pre-release candidate notes

Dev Inspector 1.0.0

Planned release for macOS 14.0 or later. Public download is not available yet; these notes describe the current candidate.

Inspection features

  • X.509 certificate identity, dates, extensions, fingerprints and public-key details.
  • Certificate ASN.1 structure and linked Hex byte ranges.
  • Provisioning profile metadata, devices, entitlements, embedded certificates and raw plist.
  • IPA app/archive metadata, architectures, frameworks, extensions, embedded profile and privacy manifest.
  • XML/binary plist, precision-preserving JSON numbers and namespace-aware XML with tree, text, search and copy.
  • System, Light and Dark appearance, and optional local recent-file history.

Known limitations

  • Certificate date status is not trust validation.
  • IPA metadata inspection is not signature or installation validation.
  • Profile parsing is not Apple trust validation.
  • ASN.1 and Hex are certificate inspection views, not general-purpose file tools.
  • Raw → Tree navigation and XML Pretty are not implemented. Schema validation and XPath are not included.
  • Automatic updates are not implemented.
  • Input-size, depth, node and copy limits apply.
  • Public download is pending signed/notarized distribution; Intel real-machine validation is pending.

Local-first, read-only

Files are processed locally without upload or account registration. Inspection does not modify source files. Read the current privacy statement.
