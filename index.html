Eight inspection views. Clear answers, with clear boundaries.

01

X.509 Certificate

Read the identity. Understand the dates.

Subject, issuer, serial number, validity dates, extensions, fingerprints and public-key details. PEM, DER and bare Base64 certificate input.

Date validity status is not certificate trust validation.

02

ASN.1

See the structure behind a certificate.

Explore certificate nodes, decoded values, encoding warnings and linked byte ranges.

Available within certificate inspection; not a general entry point for arbitrary ASN.1 documents.

03

Hex

Connect fields to their bytes.

Follow certificate structure selections into raw Hex and copy bounded byte ranges.

A certificate inspection view, not a standalone Hex editor.

04

Provisioning Profile

Make signing metadata readable.

Inspect team information, App ID, entitlements, devices, embedded certificates and raw plist.

Profile parsing does not assert Apple trust validation.

05

IPA

Explore what an app archive contains.

App metadata, architectures, frameworks, extensions, embedded profile, privacy manifest and file metadata.

Metadata inspection does not verify IPA signatures or installability.

06

Property List

Browse XML and binary plist.

Typed tree, raw text, search and copy. Binary input includes clearly labeled generated XML.

Read-only views keep the inspected source file unchanged.

07

JSON

Keep numbers as they were written.

Precision-preserving number tokens, duplicate-key detection, tree, raw text, search, copy and Pretty.

Duplicate keys are rejected. Tree → Raw is supported; Raw → Tree is not implemented.

08

XML

Inspect structure with namespaces intact.

Namespace-aware tree, attributes, mixed text, raw text, search and copy. External DTDs and custom entities are not loaded.

XML Pretty, schema validation and XPath are not included.
