Privacy

Your files stay on your Mac.

How the current app and this static website handle data. This describes current behavior, not a promise about every future version.

Local file processing

Dev Inspector processes inspected files locally on your Mac. The app does not upload inspected files or file contents. Inspection does not require a network connection. Read-only inspection does not modify inspected source files.

Accounts, analytics and crash reporting

No account is required. No analytics SDK or third-party crash reporting service is included in the app. macOS may provide its own system diagnostics under your system settings; those are separate from Dev Inspector.

Recent files

If enabled, recent file metadata is stored locally in app preferences: file paths, detected types and opening times. The app does not copy inspected files into history. You can disable new history in Settings and use Clear Recent Files to remove saved history. Disabling history alone does not clear existing entries.

Trial and offline License verification

The app stores local Trial state in its own macOS Keychain item and a local Application Support file. The 14-day Trial starts after the first successful inspection of a supported file. Imported signed License data is stored locally and verified offline using a public key. License verification does not require an account or send inspected files, license contents or device identifiers to a server.

Clipboard

Copy actions place selected data into the macOS clipboard. Treat copied certificate, profile or file information with the same care as the source. Clipboard managers and other software are outside the app’s control.

Updates

Automatic updates are not currently implemented. The app does not check for updates in the background.

This website

This static website includes no analytics scripts, tracking pixels, cookies, account system or contact form. It uses local images and system fonts. The planned hosting service is GitHub Pages. GitHub logs visitor IP addresses for security, separately from this website’s own code. See the GitHub Privacy Statement. Website requests are separate from inspecting files in the Mac app.

Questions

For product support, email dragon_kang_app@163.com. See the Support page for how to prepare a sanitized report. If you choose to email support, your email provider and our support mailbox handle the sender address, message and attachments. Send only information you choose to share, and sanitize it first. Do not email private keys or License files.
